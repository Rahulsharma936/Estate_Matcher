# Starting the Application

To run the application, you need to start both the backend and frontend servers.

## 1. Start Backend
In a new terminal:
```bash
cd backend
npm run dev
```

## 2. Start Frontend
In a new terminal:
```bash
cd frontend
npm run dev
```

The frontend will be available at http://localhost:5173 and the backend at http://localhost:5000.
